# LabProg III - Instituto Militar de Engenharia (IME)

Study repository for the Programming Laboratory III course at the Computer Engineering department of IME.

## 📌 Course Objectives
This course covers modern technologies for web and mobile development, focusing on the ecosystem of JavaScript and TypeScript, including frameworks and React Native.

## 🛠 Tech Stack
- [JavaScript](https://mozilla.org) (ES6+)
- [TypeScript](https://typescriptlang.org)
- [React](https://reactjs.org) / Web Frameworks
- [React Native](https://reactnative.dev)

## 📂 Repository Contents
- `cap-3/`: Exercises from Chapter 3 regarding Advanced JavaScript.
- `cap-4/`: Exercises from Chapter 4 regarding TypeScript.
- `cap-5/`: Exercises from Chapter 5 regarding JavaScript Frameworks.
- `cap-6/`: Exercises from Chapter 6 regarding React Native.
